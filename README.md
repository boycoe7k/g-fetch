# g-fetch

Vercel-ready GHFetch developer tool.

Features:
- GitHub latest release lookup
- GitHub release asset downloads
- GitHub repository ZIP downloads
- GitHub URL or owner/name input
- Public website HTML source viewer
- Copy/download source
- Linked CSS, JavaScript, image and media asset scanner
- View/download public text assets

Deploy by importing this repository into Vercel. Build command: `npm run build`; output: `dist`.
